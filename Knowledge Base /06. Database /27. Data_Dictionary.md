## 1. Overview

The CARIVIX AI Data Dictionary provides a standardized reference for all analytical datasets prepared for AI/ML and Dashboard consumption. It documents attribute names, descriptions, data types, units, sources, and data-quality metrics for each field across the six analytical datasets.

This dictionary enables Data Scientists, Analysts, and Dashboard developers to understand dataset structures, interpret attributes correctly, and integrate data consistently.
