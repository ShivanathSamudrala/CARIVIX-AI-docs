## 1. Overview

This document details the complete PostGIS database workflow and REST API integration for the CARIVIX AI GIS module. It covers database architecture, spatial data migration, API endpoint design, and the end-to-end data flow from data ingestion to visualization.

The workflow ensures that all spatial data is permanently stored, efficiently indexed, and served through a robust API layer for frontend consumption.

---

## 2. PostGIS Database Architecture

### 2.1 Database Configuration

| Setting | Value |
|---|---|
| Host | localhost |
| Port | 5432 |
| Database Name | telangana_gis |
| Spatial Extension | PostGIS (`CREATE EXTENSION postgis;`) |
| Default Schema | public |
| CRS | SRID 4326 (WGS 84) |

### 2.2 Roles & Permissions

A dedicated least-privilege role was created for the project to ensure security and auditability:

```sql
CREATE USER telangana_user WITH PASSWORD '••••••••••';
GRANT ALL PRIVILEGES ON DATABASE telangana_gis TO telangana_user;
GRANT ALL ON SCHEMA public TO telangana_user;
GRANT CREATE ON SCHEMA public TO telangana_user;
```

**Why Least-Privilege?**

- Limits damage from mistakes or compromised credentials
- Keeps an audit trail of which role is doing what
- Follows production-grade security best practices

## 4. FastAPI Server Implementation

### 4.1 Server Setup

```python
from fastapi import FastAPI, HTTPException, Query
from fastapi.middleware.cors import CORSMiddleware
from fastapi.middleware.gzip import GZipMiddleware
from fastapi.responses import FileResponse, JSONResponse
import os
import json

app = FastAPI(
    title="India Administrative Boundary & Point GIS API",
    description="High-performance WebGIS spatial data delivery API",
    version="1.0.0"
)

# Enable CORS for external client access
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_methods=["GET"],
    allow_headers=["*"]
)

# Enable Gzip compression (70-80% compression on responses > 1KB)
app.add_middleware(GZipMiddleware, minimum_size=1000)
```

### 4.2 Boundary Endpoint Implementation

```python
BOUNDARIES_MAP = {
    0: "assets/optimized_geojson/gadm41_IND_0_opt.geojson",
    1: "assets/optimized_geojson/gadm41_IND_1_opt.geojson",
    2: "assets/optimized_geojson/gadm41_IND_2_opt.geojson",
    3: "assets/optimized_geojson/gadm41_IND_3_opt.geojson"
}

@app.get("/api/v1/boundaries/{level}", 
         summary="Get Boundary GeoJSON Payload",
         tags=["Administrative Boundaries"])
async def get_boundary(
    level: int,
    state: str = Query(None, description="Optional State filter")
):
    if level not in BOUNDARIES_MAP:
        raise HTTPException(status_code=400, 
                           detail="Invalid boundary level. Choose 0, 1, 2, or 3.")
    
    file_path = os.path.join(BASE_DIR, BOUNDARIES_MAP[level])
    if not os.path.exists(file_path):
        raise HTTPException(status_code=404, 
                           detail=f"Boundary file level {level} not found.")
    
    # Server-side state filtering
    if state and level > 0:
        with open(file_path, "r", encoding="utf-8") as f:
            data = json.load(f)
        filtered_features = [
            feat for feat in data.get("features", [])
            if feat.get("properties", {}).get("NAME_1", "").lower() == state.lower()
        ]
        return JSONResponse(content={
            "type": "FeatureCollection", 
            "features": filtered_features
        })
    
    return FileResponse(file_path, media_type="application/geo+json")
```

## 7. Troubleshooting Log

| Issue | Cause → Resolution |
|---|---|
| Layers ticked but not visible | Unticked checkboxes / draw order / empty layers → Reordered layers; re-ran QuickOSM |
| Population values look like text | Comma-formatted numbers joined as text → Inline expression: `to_int(replace(...))` |
| Field Calculator crashes QGIS | Unstable dialog → Avoided Field Calculator; used inline Symbology expression |
| Entire project lost after crash | QuickOSM layers are memory-only → Migrated every layer to PostGIS |
| "permission denied for schema public" | PostgreSQL 15+ default privilege change → `GRANT ALL ON SCHEMA public TO telangana_user` |
| Population table invisible in Data Source Manager | Non-spatial tables hidden by default → Enabled "Also list tables with no geometry" |
