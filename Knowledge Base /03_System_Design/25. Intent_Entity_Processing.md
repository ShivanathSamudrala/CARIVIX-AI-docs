## 1. Overview

The Intent/Entity Processing layer is the core NLP understanding layer of CARIVIX. It converts a user query into structured information by predicting the user's intent and extracting relevant entities required to execute the request.

**The Layer Consists of Two Processing Components:**

- **Intent Processing** – Determines what the user wants
- **Entity Processing** – Extracts the required parameters

---

## 2. Intent Processing

### 2.1 Intent Processing Flow

```
User Query
    ↓
Text Preprocessing
    ↓
TF-IDF Vectorizer
    ↓
Logistic Regression
    ↓
Predicted Intent
    ↓
CARIVIX Intent Category
```

### 2.2 Intent Classification Implementation

```
Input Text
    ↓
TF-IDF
    ↓
Logistic Regression
    ↓
Intent Prediction
```

The intent dataset is loaded from the CARIVIX intent classification dataset and divided into training and testing data.

**Intent Name Normalization:**

- `gis_query` → `gis_queries`
- `research_query` → `research_queries`

The trained model is then used for new CARIVIX queries.

### 2.3 Intent Output

The system produces:

```json
{
  "query": "Show traffic congestion in Hyderabad",
  "intent": "smart_city_analysis"
}
```

## 3. Entity Processing

### 3.1 Entity Processing Workflow

The entity-processing workflow extracts important information from the query that is required to execute the user's request.

```
User Query
    ↓
spaCy NLP Model
    ↓
Named Entity Detection
    ↓
CARIVIX Entity Mapping
    ↓
Custom Metric Detection
    ↓
Structured Entities
```

### 3.2 Entity Types

| Entity Type | Example |
|---|---|
| LOCATION | Hyderabad |
| ORGANIZATION | Microsoft |
| DATE | 2025 |
| METRIC | Revenue |
| CATEGORY | Traffic / GDP / Sales |

### 3.3 spaCy to CARIVIX Entity Mapping

The notebook maps standard spaCy labels into CARIVIX-specific labels.

| spaCy Label | CARIVIX Entity |
|---|---|
| GPE | LOCATION |
| LOC | LOCATION |
| FAC | LOCATION |
| ORG | ORGANIZATION |
| DATE | DATE |
| TIME | DATE |

### 3.4 CARIVIX-Specific Metric Extraction

The project also contains additional CARIVIX-specific extraction for metrics such as:

- Revenue
- Sales
- Profit
- GDP
- Inflation
- Market Share
- Traffic
- Population
- Growth
- Forecast-related metrics
