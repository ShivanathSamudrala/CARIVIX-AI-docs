## 5. Key SQL Queries & Expressions

### 5.1 Population Clean Expression (QGIS Symbology)

```sql
to_int(replace("telangana_population_population", ',', ''))
CREATE USER telangana_user WITH PASSWORD '••••••••••';
GRANT ALL PRIVILEGES ON DATABASE telangana_gis TO telangana_user;
GRANT ALL ON SCHEMA public TO telangana_user;
GRANT CREATE ON SCHEMA public TO telangana_user;

CREATE INDEX idx_telangana_districts_geom 
ON telangana_districts USING GIST (geom);

CREATE INDEX idx_gadm41_ind_0_geom 
ON gadm41_ind_0 USING GIST (geom);
```

## 8. Troubleshooting Quick Reference

| Issue | Resolution |
| :--- | :--- |
| Layers not visible | Reorder layers (points/lines on top, polygons below). |
| Population text issue | Use inline expression: `to_int(replace(...))`. |
| QGIS Field Calculator crashes | Avoid Field Calculator; use inline Symbology expression. |
| Project data lost after crash | Migrate all layers to PostGIS permanently. |
| Permission denied on schema | Run `GRANT ALL ON SCHEMA public TO telangana_user;`. |
| Population table invisible | Enable "Also list tables with no geometry" in Data Source Manager. |
