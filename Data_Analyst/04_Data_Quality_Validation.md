# Data Quality and Validation

## 1. Overview

Data quality and validation activities were carried out across all four sprints, progressively strengthening the reliability, consistency, and integrity of the analytical datasets that support CARIVIX AI.

| Sprint | Focus |
|---|---|
| Sprint 1 | Initial Quality Checks |
| Sprint 2 | Post-Standardization Validation |
| Sprint 3 | Final Analytical Dataset Validation |
| Sprint 4 | Final Analytical Quality Review |

---

## 2. Sprint 1 — Initial Quality Checks

Initial quality checks included:

| # | Check |
|---|---|
| 1 | Row and column counts |
| 2 | Missing values |
| 3 | Blank values |
| 4 | Duplicate records |
| 5 | Infinity values |
| 6 | Data types |
| 7 | Dataset completeness |

> The initial **Research Intelligence** dataset contained **12,783 duplicate rows**, which were identified during the initial data-quality work.

---

## 3. Sprint 2 — Post-Standardization Validation

The team continued quality validation after standardization.

### Checks Performed

- Dataset structure
