## 6. RAG Pipeline Architecture

```
User Query
    ↓
Query Processing
    ↓
Embedding Model
    ↓
Hybrid Vector + Keyword Search
    ↓
Top 20–50 Results
    ↓
Reranker
    ↓
Top 5–10 Relevant Results
    ↓
LLM
    ↓
CARIVIX Answer / Report / Recommendation
```
