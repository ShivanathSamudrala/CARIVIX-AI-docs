Feature-importance analysis was performed using Random Forest models, validation-based permutation importance, and TF-IDF with Logistic Regression for the research dataset. Baseline models were also developed for all five datasets.

The strongest reported baseline results were obtained for:

| **Dataset**                 | **Modeling Task**                                | **Reported Result**                                 |

The Market Analysis and Economic Trend regression models require additional improvement through stronger preprocessing, outlier treatment, feature selection, and hyperparameter tuning.

### 5.1.4. Technical Observations

Runtime warnings were generated during logarithmic transformation:

RuntimeWarning: invalid value encountered in log1p

This indicates that some values may have been negative, invalid, or unsuitable for the applied transformation.

Recommended handling:

invalid_values = df\[column\].notna() & (df\[column\] \< 0)

df\[f"{column}\_Log_Invalid_Flag"\] = invalid_values.astype(int)

df\[f"{column}\_Log"\] = np.where(

df\[column\] \>= 0,

np.log1p(df\[column\]),

np.nan

)

Very large percentage changes were also observed in certain records. Such values may result from denominators close to zero.

A denominator-risk flag should be added in future processing:

df\["Percentage_Change"\] = np.where(

df\["First_Year_Value"\].abs() \> 0,

(

(df\["Latest_Year_Value"\] - df\["First_Year_Value"\])

/ df\["First_Year_Value"\]

) \* 100,

np.nan

)

### 5.2.4. Leakage Considerations

Worker-derived features must be reviewed carefully when predicting worker-related target variables. Features generated directly from the target or calculated using the target may cause data leakage.

The following types of features should be excluded when predicting workforce-related targets:

| **Leakage-Prone Feature Type**              | **Reason**                                  |
|---------------------------------------------|---------------------------------------------|
| Target-derived log features                 | Direct transformation of the target.        |
| Target-derived ratios                       | Contains target information mathematically. |
| State totals containing the target record   | May indirectly reveal the target.           |
| State averages containing the target record | May create target leakage.                  |
| Worker-share features                       | Directly depends on workforce values.       |

# 8. Leakage and Redundancy Review

Feature leakage and redundancy were reviewed across all datasets.

## 8.1. Feature Types Reviewed

| **Feature Type**                   | **Risk**                                                          |
|------------------------------------|-------------------------------------------------------------------|
| Target columns                     | Directly reveal the output variable.                              |
| Target-encoded columns             | May represent the target in numeric form.                         |
| Target-derived ratios              | Can mathematically expose the target.                             |
| Future-period features             | May use information unavailable at prediction time.               |
| Post-event traffic variables       | May be measured after the event being predicted.                  |
| Constant columns                   | Provide no predictive information.                                |
| Raw and log-transformed duplicates | May create unnecessary redundancy.                                |
| Identifier columns                 | May have limited independent analytical value.                    |
| Highly correlated yearly features  | May distribute or distort feature importance.                     |
| Group aggregates                   | May create leakage if calculated using all data before splitting. |

## 8.2. Recommended Leakage-Safe Processing

For future production modeling:

| **Recommendation**                                                      |
|-------------------------------------------------------------------------|
| Split data before calculating target-dependent aggregations.            |
| Fit encoders only on the training dataset.                              |
| Apply the same fitted transformations to validation and testing data.   |
| Calculate group-level statistics using training data where appropriate. |
| Exclude future-period variables from historical prediction tasks.       |
| Maintain a target and leakage register for each dataset.                |
| Document all removed variables and the reason for removal.              |

## 11.4. Percentage-Change Risks

Very large percentage changes may occur when:

| **Cause**                                               |
|---------------------------------------------------------|
| The starting value is close to zero.                    |
| The first available value is unusually small.           |
| The latest value uses a different scale.                |
| A structural break exists in the data.                  |
| The first valid observation was incorrectly identified. |
| The denominator is missing or invalid.                  |

A denominator-risk feature should be added to identify values where the starting value is near zero.
