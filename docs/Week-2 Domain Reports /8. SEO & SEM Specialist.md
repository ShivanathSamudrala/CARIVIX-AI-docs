### 1. Dual Strategy: SEO vs SEM

**SEO Engine — Long-Term Organic Growth:** Position CARIVIX as a 'digital think tank' — build equity, not just keyword rankings.
- **Target:** Informational and long-tail commercial queries (e.g., 'AI smart city traffic prediction')
- **GEO Optimization:** Publish definition-first content tailored for AI overviews (ChatGPT, Perplexity)
- **Data PR:** Use CARIVIX's own predictive engine (ARIMA, Prophet) to publish 'Hero Reports' (e.g., 2030 Traffic Predictions) as magnets for high-authority backlinks from tech journals
- **Technical:** Strict Information Architecture (Home → Platform → Solutions → Industries) + robust Schema markup

**SEM Engine — Immediate Paid Acquisition:** Runs in parallel while SEO matures over 3–6 months; strictly focused on bottom-of-funnel buyers.
- **Target:** High-intent, competitor comparison queries (e.g., 'Palantir alternative', 'Enterprise AI Platform')
- **Google Search Ads:** Capture active searchers and route them to the ROI Calculator or Demo booking pages
- **LinkedIn ABM:** Target specific decision-makers (Chief Data Officers, Urban Planners) via gated educational resources
- **Retargeting:** Recapture visitors who view pricing or solutions pages but drop off

### 2. Strategic Evaluation & Risk Analysis

**Why This Framework Will Succeed:** Acknowledges the shift to Generative Search (GEO). Correctly separates the SaaS self-serve buyer from the Government buyer — government procurement requires DPDPA 2023 compliance and trust, not just a 'Start Free Trial' button.

**Risk Factors to Monitor:**

| Risk | Detail | Required Action |
|---|---|---|
| Keyword Cannibalization | 5 intelligence domains risk pages competing against each other (e.g. /business-intelligence vs /economic-intelligence) | Strict keyword-to-page mapping — each domain page must rank independently |
| Content Authenticity | Calendar demands 24 highly technical posts in 3 months; generalist writing will fail with Data Scientists and Government Officers | All content must demonstrate E-E-A-T expertise |

### 3. Four-Phase Implementation Roadmap

| Phase | Focus | Key Actions |

### 1. GA4 Architecture & Naming Conventions

**Event-Driven Model — 3-Step Data Chain:**

| Step | What Happens |
|---|---|
| 1 — The Action | A visitor interacts with an element on the CARIVIX platform |
| 2 — The Signal (dataLayer.push) | The application pushes an event and its structured contextual parameters into the browser's data layer |
| 3 — The Catch (GTM) | Google Tag Manager captures the event via a Custom Event trigger and dispatches the payload to GA4 |

**Strict Event Naming Convention:**
- **Syntax (snake_case):** Lowercase letters separated by underscores only (e.g., `trial_signup_completed`)
- **Verb-at-the-End:** Suffix must represent the completed action (e.g., `form_submitted`, `pricing_tier_viewed`)
- **Length Limits:** Event names and custom parameter keys must remain under 40 characters
- **Value Consistency:** Fixed parameter values must follow standardized lowercase strings (e.g., `revenue_stream` = 'saas', 'government', or 'consulting')
- **Reserved Prefix Exclusion:** Never start custom event names with `google_`, `ga_`, or `firebase_`
