### Evaluation Metrics

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

The baseline experiment was used to establish an initial machine-learning model and evaluate its performance using standard regression metrics.

### RAG Retrieval Validation

The initial retrieval approach used character similarity between the user query and stored questions. This produced false matches because common phrases such as **"what is"** could influence similarity.

The improved retrieval logic included:

- Query normalization
- Punctuation removal
- Meaningful-word extraction
- Stop-word removal
- Relevant-word comparison
- Word-overlap validation
- Rejection of queries without meaningful matches

This improved the ability to distinguish supported queries from unrelated or unsupported questions.
