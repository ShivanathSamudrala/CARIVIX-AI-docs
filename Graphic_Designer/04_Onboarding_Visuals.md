# CARIVIX AI — Onboarding Design System & Visual Communication

## 1. Overview

The CARIVIX AI Onboarding Design was created to **introduce new users to the platform**, explain its major capabilities, and guide them toward using the product. The onboarding experience converts the technical capabilities of CARIVIX AI into a **simple, visual, and sequential communication flow**.

The onboarding designs were created for both **mobile and desktop presentation**, with a strong focus on:

- Clear messaging
- Supporting illustrations
- Consistent branding
- Simple navigation

### Overall Objective

To help users understand:

| # | Question Answered |
|---|---|
| 1 | What CARIVIX AI is |
| 2 | What the platform can do |
| 3 | How it processes information |
| 4 | How AI supports decision-making |
| 5 | How users can collaborate and use insights |
| 6 | How to begin using the platform |

> The Week 3 design work specifically included defining the onboarding communication flow, planning product walkthrough visuals, designing onboarding screens, creating feature introduction graphics, and developing user guidance components.

---

## 2. Onboarding Communication Flow

The onboarding experience was structured as a **step-by-step product introduction** rather than presenting all product capabilities on a single screen.

### Overall Progression

```
Welcome → Understand → Analyze → Visualize → Predict → Collaborate → Get Started
```

This structure **gradually introduces** the user to the platform before directing them into the actual product.

> The visual sequence uses **numbered screens and pagination indicators** so that users can understand their position within the onboarding process.

## 10. CTA & Navigation Components

Navigation was kept **simple** throughout the onboarding flow.

### Primary Controls

| Control | Purpose |
|---|---|
| **Next** | Move to the next onboarding screen |
| **Get Started** | Enter the product at the end of onboarding |
| **Sign In** | For existing users who already have an account |
| **Skip** | Allow users to bypass the onboarding sequence |
| **Back** | Return to a previous onboarding screen (in versions where this is supported) |

> These controls are designed consistently so users can easily understand **how to navigate the sequence**.

## 11. Pagination System

Pagination indicators were used at the **bottom of the onboarding screens**.

### The System Visually Indicates

| # | Indicator |
|---|---|
| 1 | Current screen |
| 2 | Total onboarding steps |
| 3 | User progress |

> The **active step** is highlighted using the primary brand color while **inactive steps** remain visually subtle.

> This gives users a simple understanding of where they are within the onboarding journey.
