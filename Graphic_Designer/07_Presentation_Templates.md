# CARIVIX AI — Presentation Templates

## 1. Overview

The CARIVIX AI Presentation Template System was designed as a **reusable corporate presentation framework** for communicating the company, product, services, solutions, and business information in a consistent and professional format.

### Supported Presentation Types

| # | Presentation Type |
|---|---|
| 1 | Company presentations |
| 2 | Product presentations |
| 3 | Investor presentations |
| 4 | Corporate meetings |
| 5 | Startup introductions |
| 6 | Client proposals |
| 7 | Business reviews |
| 8 | Project overviews |
| 9 | Enterprise documentation |

> **Main Objective:** To create a professional, reusable, and visually consistent presentation system that allows **content to be replaced while maintaining the CARIVIX visual identity**.

## 15. Typography System

The presentation template uses two primary fonts:

| Font | Purpose |
|---|---|
| **Primary — Inter** | Main titles, section titles, large headlines, cover page headings |
| **Secondary — DM Sans** | Body text, paragraphs, supporting descriptions, small labels |

### Typography Hierarchy

| Element | Font | Weight |
|---|---|---|
| Main Heading | Inter | Bold |
| Section Heading | Inter | Semi Bold |
| Body Text | DM Sans | Regular |
| Small Labels | DM Sans | Medium |

> This combination creates a **distinction between high-level information and supporting content**.

## 20. Content Hierarchy

The presentation system establishes a **clear hierarchy** between:

```

↓
Supporting Description
↓

```

> This makes the **most important information immediately visible** while allowing secondary information to remain available without competing with the main message.

## 23. Enterprise Presentation Standards

The presentation work was also supported by research into **enterprise presentation standards**.

### Documented Standards

| # | Standard | Purpose |
|---|---|---|
| 1 | **Consistent Branding** | Maintaining consistent colors, typography, iconography, and UI components |
| 2 | **Visual Hierarchy** | Using clear heading sizes and spacing to prioritize information |
| 3 | **Clean Layout** | Avoiding clutter and maintaining proper alignment |
| 4 | **Typography** | Defining heading, subheading, and body styles |
| 5 | **Color Usage** | Using color to support communication rather than distract from the content |
| 6 | **Reusable Components** | Standardizing elements such as cards, forms, tables, navigation, and other interface elements |
| 7 | **Accessibility** | Maintaining readable text and sufficient contrast |
| 8 | **Responsive Design** | Considering different desktop, tablet, and mobile screen sizes |

> These principles informed the **broader CARIVIX design direction**.

↓

↓
Typography & Hierarchy
↓

↓
Cards & Components
↓
