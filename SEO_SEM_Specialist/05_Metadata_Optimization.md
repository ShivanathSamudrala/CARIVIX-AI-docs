## 4. Image ALT-Text Requirements

### 4.1 Core ALT-Text Requirements

| No. | Requirement | Specification |
|---|---|---|
| 1 | Descriptive | Clearly describe the subject and purpose of the image |
| 2 | Concise | Keep ALT text brief and meaningful; ideally around 125 characters or less where practical |
| 3 | Contextual | Align the ALT text with the surrounding page content |
| 4 | Keyword Relevant | Include the primary keyword only when it naturally describes the image |
| 5 | No Keyword Stuffing | Do not add multiple or unrelated SEO keywords |
| 6 | Unique | Use unique ALT text for distinct images |
| 7 | Accessibility First | Write ALT text so screen-reader users can understand the image's purpose |
| 8 | Functional Images | Describe the action or destination when an image functions as a link or button |
| 9 | Decorative Images | Use empty ALT text (`alt=""`) for purely decorative images |
| 10 | Text in Images | Important information shown within images should also be available as HTML text |
